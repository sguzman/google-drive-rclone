Privacy policy

This policy applies to the personal-use Google Drive archive configuration described on the homepage and its Google OAuth desktop client. It does not represent a hosted Google Drive backup service.

Google account information accessed

With the account owner's consent, the locally running rclone program uses https://www.googleapis.com/auth/drive.readonly to read the Google Drive file and folder list, file metadata, and file contents necessary to create a personal local backup. The configuration is not intended to modify, upload or delete cloud files.

How the data is used and stored

Google Drive data is downloaded directly by rclone from Google to storage controlled by the account owner. OAuth credentials and refresh tokens remain in the owner's local rclone configuration and are not uploaded to this documentation website or public source repository.

This configuration does not use Google Drive data for advertising, sale, profiling, or distribution to other users. The publicly hosted pages contain no Google Drive files, user tokens, or login functionality.

Sharing and hosting

The local archive does not intentionally send backed-up Google Drive content to third parties. Google provides the API that the desktop program reads. GitHub Pages hosts this informational website and may process ordinary website-access information under GitHub's own privacy terms; it is not a storage location for Google Drive backups.

Retention and deletion

Local copies are retained until the account owner deletes them. Revoking the application's Google Account authorization stops future API access; it does not automatically delete local archival copies. The owner can remove local files and the locally stored OAuth credentials separately.

Security and contact

Access to OAuth credentials and backed-up files is controlled by permissions on the account owner's machine. The source code is available from the project repository, which also provides its public issue tracker for project questions.
