This privacy policy covers the personal Google Drive Local Archive workflow. The workflow operates locally and is not offered as an online service to other users.

Google user data accessed

With the account holder's authorization, the application uses Google Drive's read-only API permission to list files and folders; read filenames, sizes, checksums, file identifiers and other metadata; and download file contents for local archival and integrity checks.

How data is used

Google Drive data is used solely to preserve local backup copies and verify duplicates. The software does not use the data for advertising, profiling, model training, or unrelated purposes. It does not modify or delete source files in Google Drive.

Where data is stored

Downloaded files and backup metadata are stored on the account holder's own local disk. OAuth client credentials and access/refresh tokens are stored in the owner's local rclone configuration. This website does not receive, store, or process that data.

Sharing and transfers

The workflow connects directly between Google's APIs and the account holder's own machine. The project operator does not sell Google user data or intentionally disclose it to advertisers, data brokers, or third-party services. Standard communications with Google's APIs are required to access Drive.

Retention and deletion

The account holder controls local downloaded copies, logs and credentials, and can remove them from their device. Revoking the application's access in the Google Account permissions page stops future authorized access but does not automatically erase existing local archives.

Website

This page is a static GitHub Pages site. The site contains no sign-in form, tracking scripts, advertisements, or upload functionality. GitHub may process ordinary website requests according to its own terms and privacy policy.
