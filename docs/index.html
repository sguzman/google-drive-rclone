This is the information page for a personal Google Drive archival workflow built with rclone. It is not a commercial service or a hosted Drive application.

What it does

The software runs on the owner's own Linux computer. After the owner authorizes access to their Google Drive, it lists files, downloads copies to an attached local disk and preserves distinct files that happen to share names. Transfers are one-way: cloud to local storage.

Permissions

It requests https://www.googleapis.com/auth/drive.readonly, allowing it to read Drive file metadata and content for backup. This scope does not permit modifying or deleting files in Google Drive.

Where information goes

File contents and OAuth credentials remain on the user's own computer. This static informational site does not accept uploads, provide sign-in, or receive Drive files or authorization tokens.

See the privacy policy for details about access, storage, and sharing.
