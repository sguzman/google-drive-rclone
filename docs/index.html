Personal Drive Archive

This site documents a personal-use Google Drive backup configuration based on rclone, an open-source command-line file-transfer tool. The desktop OAuth client authorizes the account owner to download their own Google Drive files.

What the application does

After the account owner authorizes Google Drive access, rclone runs locally and copies files from that account's Google Drive to a local storage disk. The configuration uses the drive.readonly permission, which allows reading file contents and metadata but does not grant permission to change or delete cloud files.

This website is documentation only. It does not provide an online login, receive Google OAuth tokens, or proxy Google Drive content. The software runs on the account owner's computer.

Data and privacy

See the privacy policy for how Google user data is accessed, stored, retained and controlled in this setup.

Implementation

The archive scripts and their operation are documented in the public source repository. The private OAuth credentials and backed-up personal files are not in that repository.
